Using your real first name feels personal, but it doesn't prove the email is legitimate — scammers frequently already have names attached to email addresses from earlier data breaches, and can drop them into a template just like this.

We received a request to reset your Facebook password.
Enter the following password reset code:

66631625
Never type a password reset code into a page you clicked through to from an email. A common version of this scam has the attacker trigger a real reset on your actual account, then send you this same real code — if you enter it on a fake page like this one, it gets relayed straight to the real service to finish the attacker's own reset, not yours.

Alternatively, you can directly change your password.

Offering a code AND a button gives you two different ways to fall for the same request — if the code feels suspicious, the button is there as a second attempt at getting you to click through.

Hovering shows "facebok.com" — and interestingly, Facebook actually owns that misspelled domain itself, since large companies often register common typos of their own name defensively so scammers can't use them. That's a neat fact, but not a rule to lean on: don't assume a similar-looking domain is safe just because it might be. Checking the real destination before clicking is still the habit that matters, on a computer by hovering, or on a phone or tablet by pressing and holding the link.
